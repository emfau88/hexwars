# HEXFRONT portal upload assets

All visible game copy in the screenshots is English. The PNG files satisfy Kongregate's stated minimum dimensions.

| File | Dimensions | Intended use |
| --- | --- | --- |
| `hexfront-icon.png` | 1000 × 800 | Game icon (minimum 500 × 400) |
| `01-campaign-map.png` | 1600 × 900 | Campaign atlas and mission briefing |
| `02-level-06-divided-field.png` | 1600 × 900 | Balanced Level VI gameplay (3 vs 2 cells) |
| `03-level-09-mirror.png` | 1600 × 900 | Balanced Level IX gameplay (3 vs 3 cells) |

The screenshots were captured from the local development build at a 1440 × 900 CSS viewport and exported without browser chrome. Development-only unlock/autoplay controls were used solely to stage the two balanced gameplay scenes; none of those controls or query parameters appears in the images or production bundle.

The icon was generated with OpenAI's built-in image generator using `03-level-09-mirror.png` as a palette and visual-language reference, then resized and center-cropped to the exact 5:4 portal format. It contains no text, logo or third-party mark.
